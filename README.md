# 💱 Conversor de Moedas

Aplicativo desenvolvido em Python com interface gráfica utilizando Tkinter, que realiza conversões entre diferentes moedas utilizando dados obtidos por meio de uma API de cotações.

## 🚀 Funcionalidades

- Conversão entre diversas moedas.
- Seleção da moeda de origem.
- Seleção da moeda de destino.
- Campo para informar o valor desejado.
- Consulta automática das cotações pela internet.
- Exibição do resultado da conversão.
- Tratamento de erros de conexão e consultas inválidas.
- Interface gráfica intuitiva.

## 🛠️ Tecnologias utilizadas

- Python
- Tkinter
- Requests
- AwesomeAPI

## 📋 Requisitos

- Python 3 instalado.
- Conexão com a internet.

Instale a biblioteca necessária:

```bash
pip install requests
```

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta do projeto:

```bash
cd conversor-de-moedas
```

3. Instale as dependências:

```bash
pip install requests
```

4. Execute o programa:

```bash
python conversor_moedas.py
```

## 🌐 API utilizada

[AwesomeAPI](https://docs.awesomeapi.com.br/)

A API fornece informações sobre cotações de moedas utilizadas nas conversões.

## 📚 Objetivo

Projeto desenvolvido para praticar consumo de APIs REST, requisições HTTP, manipulação de dados JSON, tratamento de exceções e desenvolvimento de interfaces gráficas.
